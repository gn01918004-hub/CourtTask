## 這裡測不到、需要在內網看一眼的項目（約 5 分鐘）

1. **字型**：版面使用 Windows 的「標楷體」，測試環境是 Linux，沒有這個字型。請確認畫面上的字是標楷體，左側說明欄的字也沒有超出格子。
2. **列印視窗**：按「列印 A3」後，請選「另存為 PDF」、邊界「無」、縮放「預設」；存出來的 PDF 用尺量一下略圖框，應該是 20 cm。8K 選印表機的自訂紙張。
3. **存檔**：按「儲存」後，看是否會跳出「另存新檔」視窗；如果內網政策擋住，會改成直接下載 .ctp 檔，兩種情況都可以正常使用。
4. **開啟本機檔**：用 Chrome 直接開 `CourtTask.html`。如果被機關的管理政策擋下，請截圖給我。
