# 法院略圖繪製系統（CourtTask）

給地政事務所用來繪製「法院／機關囑託」**現況圖、分割略圖**，並輸出 A3 1:1 成果圖與 8K 圖紙套印的單機網頁系統。
用來取代 SVMAP 裡「套疊 → 手動裁切 20×20 → 進 SVMAP 排版 → 進階輸出」的流程。

- **不用安裝、不用網路、不用伺服器**：整個 `app/` 資料夾複製到內網電腦，用 Chrome 開啟 `app/index.html` 就能用（已用 Chromium 測試）。
- 不需要任何外部函式庫，所有程式都在 `app/` 裡。

## 部署到內網

散發檔是 `dist/CourtTask_v<版本>.zip`，解壓縮後有兩種用法，功能完全相同，擇一即可：

- **單一檔案版**：`CourtTask.html`。把這一個檔案複製到內網電腦，例如 `D:\CourtTask\CourtTask.html`，用 Chrome 開啟就能使用。最容易搬移。
- **多檔版**：`app\index.html`，需要整個 `app` 資料夾一起複製。日後只更新個別檔案時比較方便。

注意事項：
- 不需要安裝、不需要網路、不需要伺服器，也不會連到任何外部網址。
- 建議建立桌面捷徑。第一次開啟時，若 Chrome 詢問是否允許存取檔案，請允許。
- 字型會使用 Windows 內建的「標楷體 (DFKai-SB)」和 Arial。
- 資料只存在本機：專案檔 (.ctp) 請自行存到固定資料夾或共用磁碟；瀏覽器另有自動暫存，但換電腦、清除瀏覽器資料就會消失。
- 範本存在瀏覽器裡，換電腦時請用「輸出 → 匯出範本檔」帶過去。
- 打包方式（開發用）：`python3 tools/build.py 1.0`，驗證方式：`node tests/dist.js`。

## 作業流程

| 步驟 | 原本的作法 | 本系統 |
|---|---|---|
| 1 | 內網資料庫套疊，產出整段地籍圖（486.dxf） | 一樣，然後在本系統按 **匯入 DXF**（可以一次選多個檔，例如 486.dxf 加上 KC1117.dxf） |
| 2 | 手動裁切成 20×20 略圖（486f.dxf） | **不用手動裁切**。略圖框會自動置中在本案地號；用「移動圖面(H)」拖曳就能改裁切位置；比例尺、裁切大小（cm）可以隨意設定；可以有**多個略圖框**，各自用不同的比例尺 |
| 3 | 在 SVMAP 畫地上物、算面積、排說明表 | 用 **點選成面(F)** 在區塊內點一下，系統會用案件線＋地籍線找出封閉範圍、算面積、自動編 A、B、C…；地上物說明表也會自動產生 |
| 4 | 在 SVMAP 填左側欄位 | 在「案件資料」頁填表，版面自動帶入。左側欄的每一列、每一欄都可以拖拉調整大小，也可以插入或刪除列欄、合併儲存格 |
| 5 | 列印 A3、進階輸出 8K | **列印 A3**（1:1）；在「輸出」頁框選範圍後按 **8K 套印**（267×388mm，左下角平移 X20、Y20，數值都可以改） |
| 6 | 核定後補日期再印 | 在「案件資料」填核定日期（或按「核定日期填今天」），右下角的日期會自動帶入，再印 A3 |

> 用 `samples/` 裡的城北 486 範例驗證過：點選成面算出的 A–I 九筆面積（96.63、104.84、103.16、107.11、212.02、110.20、88.04、90.81、75.51）和原成果圖完全一致；裁切框與原本的 486f.dxf 也相同（1/500，100m×100m）。

## 介面重點

- **左側說明欄、外框是範本的固定架構**；右邊的大框就是一張畫布，可以自由放略圖框、文字、表格、地上物表、指北針、框和線。
- 所有元件都可以拖曳、拖拉控制點縮放，移動時會自動對齊其他元件的邊緣（按住 Alt 可以取消對齊）；方向鍵微調 0.1mm（按住 Shift 則是 1mm）。
- 表格：拖拉內部格線可以調整欄寬、列高（相鄰兩格互相增減，整個表格大小不變；按住 Shift 只改一邊）。
- 文字和儲存格可以用 `{欄位}` 引用案件資料，例如 `{landNo}地號`、`比例尺： 1/{scale}`（多個略圖框可以用 `{scale1}`、`{scale2}`）。
- 地號文字、地上物編號、註記都可以直接拖曳；選取案件線後可以設成虛線、改顏色或隱藏（按住 Shift 可多選）。
- 範本：「輸出」頁可以把目前的版面存成範本（例如「現況圖」「分割略圖」），開新案件時選用；也可以匯出成 `.ctt` 檔分享給同事。
- 存檔：**儲存** 會產生 `.ctp` 專案檔（裡面包含圖資，可以完整重開）。瀏覽器也會自動暫存，萬一不小心關掉，重開就會還原。
- 需要 DXF 時：選取略圖框後按「匯出裁切 DXF」，會得到和 486f.dxf 一樣的裁切結果（另外附地上物多邊形）。

## 線型、斷線、分割線

- 線型有：實線、虛線、短虛線、長虛線、點線、一點鏈線、二點鏈線、中心線。每種用途（地籍線、現況/案件線、分割線、其他線）在「圖層」頁都可以設定預設的顏色、線寬、線型；個別線段也能單獨覆寫。
- **斷線 (B)**：在線上點一下（會鎖點到交點或端點），就能把一條線切成兩段，分別設定線型或隱藏。例如城北 486 案：位在非本案地號上的部分改成虛線。要恢復原狀，選取線段後按「取消斷線」。
- 匯入時會自動辨識內網套疊產出的圖層：`REF_LINE*`（現況/案件線）、`SPLIT`（分割線）、`LIN*`、`MERGE`（地籍線）、`PAR`（地號）、`PAR_2`、`MERGEPAR`（本案地號）。layer 0 和 SPLIT 重複的線會自動去除。
- 自繪線可以設定用途（現況線/分割線）和箭頭。

## 標籤自動避線

地號和地上物編號如果壓到線條，會在原位附近（大約一個字高的範圍內）找一個不壓線的位置；找不到就留在原位，再用滑鼠拖曳調整。手動拖曳過的位置會固定不變。這個功能可以在「圖層」頁關閉。

## 地上物說明表的樣式

說明表的欄位可以增減、調整順序，表頭文字和寬度都能改；標題列、表頭列、附註列把列高設成 0 就不顯示。內建三種快速樣式：
「編號/面積/使用地號/備註」（現況圖）、「名稱/面積/地號」（分割，例如南華 392）、「編號/坐落面積」（例如苑西 635）。
編號可以選 A、B、C… ／ 甲、乙、丙… ／ 1、2、3…。

## 理想流程（內網正式系統 → 本系統）

1. 在內網的正式計算系統裡把現況圖或分割圖套疊好，輸出 DXF。
2. 在本系統按「匯入 DXF」。如果還有另一張現況圖，再匯入一次並選「合併加入」。
3. 裁切（移動略圖框、設定比例尺）→ 點選成面、填寫說明文字 → 列印。
4. 面積以內網計算系統的結果為準：「地上物」清單的面積欄空白時顯示系統計算值，可以直接填入正式面積。

## 介面（v1.2）

- 頂端只放常用功能：檔案選單、開啟、儲存、匯入 DXF、方案、目前編輯圖層（現況／分割）、復原、縮放、列印。
- 繪圖工具放在畫布左側的直列工具列；「＋新增」選單可加略圖框、說明表、文字、表格、指北針、框、線。
- 左上的作業步驟（匯入 → 裁切 → 說明 → 資料 → 輸出）點一下就會切到該步驟要用的頁面和工具，完成的步驟會打勾。
- 表格：單擊選取、拖曳移動整個表格；**雙擊**才進入表格編輯（拉格線、點格子、Shift 多選合併），Esc 結束。
- 略圖框可分別設定「編號」「本案地號」「非本案地號」的文字大小倍率；非本案地號會盡量避開本案範圍。
- 略圖框：用選取工具時，在框內拖曳就是移圖（改變裁切位置），拖框線則是移動整個略圖框。
- 「說明」頁的清單不分現況和分割，全部列在一起、編號連續。現況和分割只影響線條圖層，顯示開關在「圖層」頁。
- 說明表可勾選「資料列高自動配合文字」。
- 左上「土地坐落」：縣市、鄉鎮、段名稱各自一格，輸入「苗栗縣」或「苗栗」都會對齊。

## 說明表與說明欄（v1.8）

- 「說明」頁：現況與分割都有項目時，會分成兩個區塊——「現況（地上物說明）」和「分割（分割方案說明）」。兩區編號各自計算，預設現況用 A、B、C，分割用甲、乙、丙，每個區塊都可以另外選編號方式。點區塊標題，就能切換新增的項目要放到哪一層。
- 兩張說明表會**接在一起、寬度一致**，附註只放在最下面那張。
- 說明表上按右鍵，可以新增欄、刪除欄、新增空白列（只出現在表格、不在圖上）。先點一格、再 Shift＋點另一格選取範圍，就能「合併選取的格子」（例如相同所有權人）或「解除合併」。一般表格的右鍵另有插入列、插入欄、刪除。
- 左側說明欄和說明表的文字**維持你設定的字高**，放不下就自動換行並加高列高，行距加寬以便閱讀。說明欄被撐高時，會從空間最多的那一列（通常是「說明」）借高度，表格總高不變。編號和面積欄則不換行。

## 說明表（v1.7）

- 現況和分割都有說明項目時，會**自動分成兩張表**：「地上物說明」列現況，「分割方案說明」列分割（預設樣式是編號／面積／所有權人）。第二張會自動接在第一張下方；手動拖動後，就改由你自己決定位置。
- 「表格樣式」改成下拉選單，放在說明表屬性的最上面。切換樣式只會換欄位，標題和附註都會保留。

## 點選成面與標號（v1.6）

- 圖上只有一種線（只有現況或只有分割）時，點選成面一律用那一種，不受頂端「編輯」停在哪一層影響。匯入時也會自動把編輯層切到圖上有的那一種。
- 兩種線都有時，才依頂端「編輯：現況｜分割」決定用哪一種當邊界。
- **標號（M）**：在略圖內點一下就放一個編號，不需要面、不計算面積，適合標示聯外道路、物品位置。標號會出現在說明表裡，面積欄空白，也可以自己填。

## 圖層鎖定（v1.5）

- 畫布右上角有「鎖定」開關，可以分別鎖住地籍線、現況、分割、其他線，「圖層」頁也有同樣的開關。
- 鎖定的圖層不會被點選、斷線、改歸屬，右鍵也點不到。例如要把現況線斷在地籍線上時，地籍線不會被誤選。不過斷點仍然可以吸附到它的交點。
- 地籍線預設是鎖定的；要修改時，點一下開關就能解除。在線段上按右鍵，也可以直接「鎖定這一層」。

## 右鍵選單（v1.4）

- **線段**：改成現況、分割、地籍線或其他線；改線型（實線、虛線、短虛、點線、鏈線）、粗細、顏色；在這裡斷線；選取相連線段；恢復預設；隱藏。如果先多選了線段，右鍵會一次套用到全部。
- **說明項目**：外框線型、編號大小、編號引線、重設編號位置、刪除。
- **地號文字、註記**：放大、縮小、顏色、恢復位置、隱藏。
- **略圖框**：鎖定或解除鎖定裁切、在這裡點選成面、置中、加註記。
- **其他元件**：複製、圖層順序、鎖定、刪除；表格還多一項「編輯表格」。
- 框外的淡灰色全圖只在「移圖」時出現。裁好之後可以勾「鎖定裁切」，框內就不會再被誤拖。

## 開啟舊系統 SVMAP 的 .m02

「開啟」可以直接選 SVMAP 的 .m02 檔（V5.00 格式），轉成本系統的專案，之後就能修改、另存成 .ctp。

- **圖紙**：標題、左側說明欄、地上物說明表、文字、框線、指北針，都會轉成可以編輯的版面元件。表格保留原本的欄寬、列高和合併儲存格。
- **地圖**：圖層名稱、線段、地號文字都會保留，每條線的顏色和虛線、文字的顏色和大小也照原樣；裁切框轉成略圖框，比例尺照舊。
- 舊系統若以縮放比例輸出圖紙（例如 0.95 倍），會自動換算成實際 mm。
- 同一檔案裡有多組相同比例尺的地圖（例如現況＋分割方案），會依座標疊在同一個略圖框。
- **限制**：
  - 舊檔沒有記錄地圖在圖紙上的位置，略圖框會自動放在外框右側，請確認一下。以城北 486 驗證，誤差約 0.2 mm。
  - 舊檔的地上物只是文字和線條，不是本系統的「地上物」。原本的說明表會轉成一般表格（可以直接改字）；若要改成自動產生的說明表，請用「點選成面」重建。
  - 底圖影像（例如調查表範本的掃描圖）目前不會轉入。
  - 本系統只能讀取 .m02，不能寫回 .m02。
- 新、舊版 SVMAP 的文字編碼不同：舊版是 Big5，新版是 Unicode，例如南華 392、苑西 635。系統會自動判斷。

## 現況與分割是兩個獨立圖層

- 現況和分割互不影響，只是疊在一起給法院看。兩層同時存在時，現況預設改成藍色實線（可在「圖層」頁調整）。
- 自動判定預設：REF_LINE0 → 現況、SPLIT → 分割；使用者也可以在「圖層」頁依自己的習慣改。工具列「編輯：現況｜分割」切換目前編輯哪一層。
- 點選成面只會用「地籍線＋目前圖層的線」當邊界，現況線不會切到分割範圍，反過來也一樣。編號各自計算（兩層都可以從 A 開始，或一層用 A、一層用甲）。
- 「地上物」頁可以分別勾選顯示或隱藏兩個圖層。說明表在屬性裡設定「列出哪一層」，現況、分割各放一張表。

## 同一張 DXF 混有現況線和分割線

依序用以下方法分開：

1. **圖層不同**：在「圖層」頁分別指定成現況或分割（內網 REF_LINE0 → 現況、SPLIT → 分割，會自動判斷）。
2. **圖層相同但顏色不同**：「圖層」頁會依顏色列出子項目，例如紅色＝現況、藍色＝分割，可以分別指定。
3. **圖層、顏色都一樣**（內網系統沒執行分割功能時常見）：按左側工具「歸屬」，在畫面上方選要「改成」哪一層，之後點哪條線就改哪條；Shift＋點＝整串相連線段，拖曳框選＝框內全部。也可以在線段上按**右鍵**直接改。

## 假合併

- 在「圖層」頁的「假合併」輸入要合併的地號（例：641、643、646）。原地號之間的界線可以選擇：**保留並打 X**、**整條隱藏**或**不合併**。
- 預設會依圖上的 X 記號自動判斷：找出 X 所在界線兩側的封閉區，抓出其中的地號。內網合併輸出的 MERGESRC（原界線）、MERGE（X 記號）、MERGEPAR（被併入的地號）圖層都能辨識。X 改由本系統畫，大小可以調整。
- 合併界線不會被當成點選成面的邊界，所以分割範圍可以直接跨過原地號界線。

## 分割案（以中溝 641 為例）

- 匯入內網產出的整段 DXF：SPLIT 圖層會自動當成分割線，分割暫編地號（如 641(1)）預設隱藏，可在「圖層」頁打開。
- 也可以用工具列「分割線(S)」自己畫分割線（會鎖點），再用「點選成面」切出各分割範圍。
- **Shift＋點選成面**：把相鄰的區塊併入目前選取的地上物，用在範圍跨過原地號界線的情形。
- 說明表可以加「所有權人」欄（快速樣式「編號/面積/所有權人」）。標題可以寫成 `{landNo}地號分割方案說明：`，圖名可以用 `{plan}` 帶入方案名稱，例如「土地複丈成果圖 ({plan})」。
- **面積配賦**：在「地上物」頁輸入登記總面積，系統會用最大餘數法把尾差分配到各筆，寫入各筆的面積欄，之後可以再手動調整。
  以 641 方案三驗證：16 筆計算面積中有 13～14 筆和成果一致，其餘只差 0.01，就是配賦的尾差。
- 略圖框可以設「文字比例」。例如 1/2000 設成 0.4，地號就不會擠成一團；每個略圖框可以各自設定。
- 地上物編號可以開啟「引線」，用在小區塊（例如 641 現況的 A1）。
- 線段可以快速改成紅、藍、黑色，或實線、虛線。地籍線含圓弧（ARC）時，面積會自動補上弓形面積修正。

## 方案（同一案件的多個方案）

工具列「方案」可以在同一個專案檔裡存放多個方案，例如中溝 641 的「現況」「分割方案1」「方案2」「方案3」。按 ＋ 會複製目前的方案（圖資、地上物、版面都會複製），之後各自修改、各自匯入不同的 DXF，再分別列印。案件資料（左側欄位）是所有方案共用的。
現況和分割也可以畫在同一張圖上（例如苑西 635 高院補繪）：現況線和分割線用不同的線型或顏色區分。

## 列印設定（很重要）

Chrome 列印視窗請設定：紙張 A3（8K 請選印表機裡的 267×388 自訂紙張）、**邊界：無**、**縮放：預設（100%）**，並勾選「背景圖形」。
也可以先選「另存為 PDF」，再用 PDF 閱讀器列印。如果印表機有固定的偏移，可以在「輸出」頁的「印表位移」校正。

```bash
node tests/geom.test.js          # DXF 解析與自動成面面積驗證

node tests/case641.js tests/out  # 重現中溝 641 方案三（1/2000、16 筆分割、所有權人、面積配賦）

```

程式結構（`app/js`）：`geom.js` 幾何（裁切、面積、自動成面）、`dxf.js` DXF 讀寫（Big5／UTF-8）、`model.js` 資料模型與預設範本、`render.js` SVG 繪製、`print.js` 列印與 DXF 匯出、`app.js` 介面操作。
